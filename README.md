# Interactive To-Do List Application

An interactive, responsive, and user-friendly To-Do List web application built using HTML5, CSS3, and JavaScript.

## Features
- **Add Tasks:** Quickly add new tasks to the list.
- **Mark Complete:** Check off completed tasks with standard checkboxes.
- **Edit & Delete:** Update existing tasks or delete unwanted ones.
- **Clear All:** Delete all tasks in one click.
- **Pending Task Counter:** Live count of incomplete tasks.
- **Local Storage Persistence:** Tasks remain saved even after refreshing or closing the browser.
- **Responsive Layout:** Designed using CSS Flexbox for smooth display across devices.
